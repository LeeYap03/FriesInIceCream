Parameters and Arguments

Parameters vs. Arguments

Parameters are variables defined in the method/function/procedure declaration.
Arguments are the actual values supplied when calling the method/function/procedure.

FUNCTION add(a, b)       ← a and b are parameters

SET result = add(5, 3)   ← 5 and 3 are arguments

Method Parameters

Method parameters are also called local parameters because they are available within the scope of the method.

Parameter Passing

Parameters can be passed in different ways depending on the programming language or system.

Value Parameter

A value parameter receives a copy of the value supplied by the caller.

  • The procedure/function can use the value.
  • Changes made to the parameter generally do not change the caller's original variable.

Reference Parameter

A reference parameter provides access to the caller's variable or object reference.

  • Changes made through the parameter can affect the original variable.
  • Useful when a procedure needs to modify a value supplied by the caller.
IN JAVA

There is no pass-by-reference
It still uses pass-by-value but instead we pass the address of the object as the value

IN, OUT, and INOUT Parameters

These parameter modes are commonly used in stored procedures, particularly in SQL/database systems.

IN

An IN parameter passes a value into the procedure.

  • Used as input.
  • Can be used in SQL statements and calculations.
  • The procedure does not use it to return a modified value to the caller.
CALL procedureName(inputValue)

Direction: Caller → Procedure

OUT

An OUT parameter passes a value out of the procedure.

  • Used to return a result from the procedure.
  • The procedure assigns or modifies the parameter.
  • The resulting value can be retrieved by the caller after the procedure executes.

Direction: Procedure → Caller

An OUT parameter is not necessarily returned as a result set; it is a separate output value. A stored procedure can also return a result set independently.

INOUT

An INOUT parameter combines the behavior of IN and OUT parameters.

  • Receives an initial value from the caller.
  • The procedure can modify that value.
  • The modified value is passed back to the caller.

Direction: Caller → Procedure → Caller
