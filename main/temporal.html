Temporal

  • Package containing interfaces, classes, and fields used by the Java date/time API
  • Provides a general way to access and manipulate date/time values
  • Commonly used with LocalDate, LocalTime, and other java.time classes
  • Two important classes are ChronoField and ChronoUnit

ChronoField

  • Enum representing individual date/time fields
  • Used to get or set specific parts of a temporal object
  • Examples include year, month, day, hour, and minute
LocalDate date = LocalDate.now();

int year = date.get(ChronoField.YEAR);
int month = date.get(ChronoField.MONTH_OF_YEAR);

Common ChronoFields

  • YEAR → year
  • MONTH_OF_YEAR → month
  • DAY_OF_MONTH → day of the month
  • DAY_OF_YEAR → day of the year
  • DAY_OF_WEEK → day of the week
  • HOUR_OF_DAY → hour of the day
  • MINUTE_OF_HOUR → minute
  • SECOND_OF_MINUTE → second
  • NANO_OF_SECOND → nanosecond
ChronoField
    ↓
Specific field
    ↓
YEAR / MONTH / DAY / HOUR / ...

ChronoUnit

  • Enum representing units of time
  • Used when adding, subtracting, or measuring amounts of time
  • Examples include days, weeks, months, years, hours, and minutes
LocalDate date = LocalDate.now();

LocalDate future = date.plus(5, ChronoUnit.DAYS);

Common ChronoUnits

  • NANOS → nanoseconds
  • SECONDS → seconds
  • MINUTES → minutes
  • HOURS → hours
  • DAYS → days
  • WEEKS → weeks
  • MONTHS → months
  • YEARS → years
  • DECADES → decades
  • CENTURIES → centuries
  • MILLENNIA → millennia
  • ERAS → eras

ChronoField vs ChronoUnit

  • ChronoField → represents a field
  • ChronoUnit → represents a unit of time
ChronoField              ChronoUnit
  YEAR                     YEARS
  MONTH                    MONTHS
  DAY                      DAYS
  HOUR                     HOURS
  MINUTE                   MINUTES

LocalDate date = LocalDate.now();

date.get(ChronoField.YEAR);       // get a field
date.plus(5, ChronoUnit.DAYS);    // use a unit
Note
  • What to use:
    ChronoField → "Which part?"
    ChronoUnit → "How much?"
