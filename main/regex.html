Pattern and Matcher in Java

Java provides the Pattern and Matcher classes in the java.util.regex package for working with Regular Expressions (Regex).

1. Pattern

  • represents a compiled regular expression.

Creating a Pattern

Pattern pattern = Pattern.compile("abc");
  • Pattern.compile() compiles the regex into a pattern structure.
  • The compiled pattern can then be used to create a Matcher.

2. Matcher

  • is used to match a compiled Pattern against a sequence of characters.
Pattern pattern = Pattern.compile("abc");
Matcher matcher = pattern.matcher("abc");

Meta Characters

Meta characters are special characters in regex that have a specific meaning.

meta character meaning
. Matches any single character
^ Beginning of the input
$ End of the input
* Zero or more occurrences
+ One or more occurrences
? Zero or one occurrence
{n} Exactly n occurrences
{n,m} Between n and m occurrences
[] Character class
() Capturing group
meta character meaning
\d Digit [0-9]
\D Non-digit
\s Whitespace
\S Non-whitespace
\w Word character
\W Non-word character

In Java strings, a backslash must usually be escaped. Therefore regex \d is written as Java string "\\d".

Capturing Groups

  • parentheses () create a capturing group.
Pattern p = Pattern.compile("(\\w+)@(\\w+\\.com)");
Matcher m = p.matcher("john@gmail.com");

There are two capturing groups:

(\\w+)          → Group 1 → "john"
(\\w+\\.com)    → Group 2 → "gmail.com"

Groups are numbered from 1.

$1 → first capturing group
$2 → second capturing group
$3 → third capturing group
...

matches()

  • Does the whole string match
Pattern p = Pattern.compile("\\d+");

Matcher m = p.matcher("12345");

System.out.println(m.matches()); // true

Matcher m = p.matcher("abc123");

System.out.println(m.matches()); // false

find()

  • searches for the next substring that matches the pattern.
  • unlike matches(), find() does not require the entire input to match.
Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("abc123xyz456");

while (m.find()) {
    System.out.println(m.group());
}

Output:

123
456

start() and end()

After a successful find(), you can use:

  • start() → starting index of the match
  • end() → index immediately after the match
Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("abc123xyz");

if (m.find()) {
    System.out.println(m.start());
    System.out.println(m.end());
    System.out.println(m.group());
}

Output:

3
6
123

replaceAll()

  • replaces every substring that matches the pattern.
Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("Java 123 is 456");

String result = m.replaceAll("#");

System.out.println(result);

Output:

Java # is #

Replacements with group references

  • $1 is used in a replacement string to refer to the text captured by the first capturing group.
    Example:
Pattern p = Pattern.compile("(\\w+)@(\\w+\\.com)");
Matcher m = p.matcher("john@gmail.com");

String result = m.replaceAll("$2 : $1");

System.out.println(result);

Output:

gmail.com : john

The pattern captures:

Group 1 → john
Group 2 → gmail.com
Note

$0 --> refers to the whole match instead of just one group

Group

  • used to get the actual text that was matched.

group()

Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("abc123xyz");

if (m.find()) {
    System.out.println(m.group());
}

Output:

123

So:

m.group()
→ returns the entire match

group(0)

You can also explicitly write:

m.group(0)

This means the same thing:

group()  = group(0) = entire match

group(1), group(2), etc.

  • return the text captured by the corresponding (...) group.
Pattern p = Pattern.compile("(\\w+)@(\\w+\\.com)");
Matcher m = p.matcher("john@gmail.com");

if (m.find()) {
    System.out.println(m.group(0));
    System.out.println(m.group(1));
    System.out.println(m.group(2));
}

Output:

john@gmail.com
john
gmail.com

Pattern Syntax Exception

  • occurs when Java cannot compile an invalid regular expression.
Pattern p = Pattern.compile("[abc");

try {
    Pattern p = Pattern.compile("[abc");
} catch (PatternSyntaxException e) {
    System.out.println("Invalid regex pattern");
}
Key idea

Pattern → defines WHAT to look for
Matcher → searches WHERE and HOW it matches
