Locale

  • represents a specific geographical, political, or cultural region to handle internationalization (I18N) and formatting.

Core Components

Component Code Standard Getter Method Example
Language (Required) ISO 639-1 (2-letter) or ISO 639-2 (3-letter) getLanguage() "en", "de"
Country/Region (Optional) ISO 3166-1 alpha-2 or UN M.49 getCountry() "US", "GB"
Variant (Optional) Vendor or browser-specific identifier getVariant() "POSIX", "PREEURO"

Creating Locales

// 1. Static factory method (Java 19+)
Locale loc1 = Locale.of("en", "US");
Locale loc2 = Locale.of("de", "DE", "POSIX");

// 2. Predefined constants
Locale loc3 = Locale.JAPAN; // ja_JP

// 3. From IETF BCP 47 language tag
Locale loc4 = Locale.forLanguageTag("en-US");

// 4. Using Locale.Builder (validates syntax)
Locale loc5 = new Locale.Builder()
    .setLanguage("fr")
    .setRegion("CA")
    .setVariant("POSIX")
    .build();

Note: Standard new Locale(...) constructors are deprecated starting in Java 19. Prefer Locale.of() or Locale.forLanguageTag().

Key Methods Summary

Method Return Type Description
getLanguage() String Retrieves the ISO language code.
getCountry() String Retrieves the ISO country/region code.
getVariant() String Retrieves the variant code.
getDisplayLanguage(Locale) String Returns a human-readable name for the language.
getDisplayCountry(Locale) String Returns a human-readable name for the country.
toLanguageTag() String Converts the locale to a BCP 47 language tag (e.g., "en-US").
Locale.getDefault() Locale Returns the current default JVM locale.
Locale.filter(...) List<Locale> Matches user-preferred language ranges against supported locales.

Using properties

messages_en.properties

greeting=Hello!
price=Price:

messages_fr.properties

greeting=Bonjour!
price=Prix:

import java.util.Locale;
import java.util.ResourceBundle;

// Change locale here to switch languages
Locale currentLocale = Locale.of("fr"); 

// Loads messages_fr.properties automatically
ResourceBundle bundle = ResourceBundle.getBundle("messages", currentLocale);

System.out.println(bundle.getString("greeting")); // Prints: Bonjour!
System.out.println(bundle.getString("price"));    // Prints: Prix:

Java matches the requested Locale to the matching messages_<lang>.properties file, or falls back to messages.properties if no match is found.
