Java APIs

Application Programming Interface (API)

  • A collection of predefined classes, methods, and interfaces provided by Java.
  • Allows us to use existing functionality instead of reinventing the wheel.
  • Java APIs are organized into packages.

Frequently Used Packages

java.lang

  • Core Java functionality.
  • Automatically imported.
  • Includes CharSequence, String, Math, System, Runtime, Object, Integer, etc.

java.util

  • General-purpose utility classes.
  • Includes collections and data structures.
  • Examples: Regex, UUID, Locale, Array, Iterables, StringTokenizer, Properties, Date, Calendar, Timezone, Scanner, Collections.

java.io

  • Input and output using streams.
  • Used for reading and writing files and other data.
  • Examples: File, FileReader, FileWriter, BufferedReader, FileOutputStream, FileInputStream, FileWriter, FileReader, PrintWriter, BufferedReader.

java.nio

  • Modern API for input/output.
  • Provides more efficient file and buffer operations.
  • Examples: Path, Files, Paths, ByteBuffer.

java.net

  • Networking functionality.
  • Used for communicating over networks.
  • Examples: URL, URI, Socket.

java.sql

  • JDBC API for working with relational databases.
  • Used to connect to databases and execute SQL.
  • Examples: Connection, Statement, ResultSet.

javax.sql

  • Extended database functionality built on top of JDBC.
  • Commonly used for DataSource and connection pooling.

java.math

  • Provides classes for precise mathematical calculations.
  • Used in data science, real world currency calculations, cryptography, and infinite precision.
  • Examples: BigInteger, BigDecimal, MathContext, Rounding Mode.

java.text

  • Formatting and parsing text, numbers, and dates.
  • Examples: NumberFormat, DecimalFormat, DateFormat, SimpleDateFormat, DateTimeFormatter.

java.time

  • Modern date and time API.
  • Examples: LocalDate, Period, LocalTime, LocalDateTime, Temporal, Duration, ZonedDateTime, Instant.

javax.swing

  • GUI toolkit for creating desktop applications.
  • Examples: JFrame, JButton, JTextField.

java.awt

  • Older GUI and graphics toolkit.
  • Provides components, layouts, colors, fonts, and graphics.

java.awt.event

  • Handles events in AWT/Swing applications.
  • Examples: mouse clicks, keyboard input, and window events.

java.xml

  • APIs for working with XML.
  • Includes XML parsing, processing, and transformation.
